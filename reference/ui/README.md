# UI reference notes

The exam-taking interface should feel like the NESA computer-based Software Engineering environment, not like a generic SaaS quiz.

Core characteristics visible in the supplied screenshots:
- dark navy exam header
- horizontal numbered question navigator
- current question strongly highlighted
- tools for flagging, highlighting, font size, colour/accessibility and information
- white/very-light-grey examination canvas
- prominent `Question N (X marks)` heading
- split-screen layouts where stimulus and response benefit from side-by-side presentation
- previous/next navigation
- dedicated instructions/start page with exam summary
- rich-text response editor with a visible word-count guide
- interactive drawing/canvas area for diagram construction
- responsive question layout chosen based on content rather than forcing one layout for every question

Do not copy NESA logos, seals, or branded icons. The goal is behavioural/interaction fidelity and a similar restrained visual language.
